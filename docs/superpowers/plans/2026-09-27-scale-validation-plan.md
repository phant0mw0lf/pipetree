# pipetree scale validation — implementation plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Validate pipetree at enterprise scale — ~100 tables across ~10 systems, 1TB and 10TB of data, five layers ending in a Kimball star schema — running for real on both Databricks and Fabric, with every connection authenticating through a managed identity instead of a stored secret.

**Architecture:** A small, additive pipetree PR adds token-based auth to the platform seam and the `sqlserver`/`kusto` readers. A new private repo, `pipetree-scale-bench`, then builds on that: OpenTofu provisions the Azure estate, dbldatagen generates the data once per scale tier, one set of pipetree YAML table definitions describes bronze→silver→integration→gold→mart, and two runners (a Databricks Asset Bundle, a Fabric notebook) execute the same YAML against a single copy of the data shared via a OneLake shortcut.

**Tech Stack:** Python ≥3.11, `uv`, pytest/ruff/pyright (matching pipetree's own tooling); OpenTofu ≥1.8 with the `azurerm`, `databricks`, and `microsoft/fabric` providers; PySpark + dbldatagen on Databricks for generation; pipetree itself as a dependency of the new repo.

**Spec:** `docs/superpowers/specs/2026-09-27-scale-validation-design.md`

## Global Constraints

- New repo is **private**, named `pipetree-scale-bench` (rename before creation if desired).
- **OpenTofu**, not Terraform, for all IaC.
- **No long-lived secrets anywhere** — no connection strings, account keys, SAS tokens, client secrets, or SQL passwords in Key Vault, OpenTofu state, or `pipeline.yaml`. Every connection authenticates as a managed identity and acquires a short-lived token at run time (spec "Authentication" section).
- **Single copy of the data** across both platforms — Fabric reads ADLS Gen2 via a OneLake shortcut; data is never re-landed into OneLake natively.
- **Sizing model**: `scale_factor` is total data size in GB — `5` (dev), `1000` (tier1/1TB), `10000` (tier2/10TB) — split 70% huge-class tables / 25% medium-class / 5% small-class (fixed row counts, scale-factor-independent).
- **Five layers**: `bronze` → `silver` → `integration` (cross-source identity resolution) → `gold` (star schema: dimensions `scd2` + `unknown_member: true`, facts) → `mart`.
- **Rollout order**: `dev`/Databricks → `dev`/Fabric → `tier1` (both platforms) → `tier2` (both platforms), non-dev tiers torn down after their report is captured.
- The one exception to "no changes to pipetree": `Platform.acquire_token` + `auth.mode: aad_token` on `sqlserver`/`kusto`, landed as its own reviewed pipetree PR before the new repo's runners use it.

## Review Focus

- **Unrecognized or misspelled `auth.mode`** (e.g. `aad-token`, `AAD_TOKEN`, empty string) must raise a clear error naming the bad value, never silently fall through to password/app-secret auth — pinned in Task 4 and Task 5.
- **Re-running generation for the same scale tier** (a real dev-loop scenario — fix a bug, regenerate) must not duplicate rows — overwrite semantics, not append — pinned in Task 17.
- **Fact-table foreign keys must all resolve to real dimension keys** after generation, even though dimension and fact tables are generated by separate calls — an off-by-one or mismatched range silently produces orphaned FKs that only surface later, in the `gold` layer — pinned in Task 18.
- **NULL match keys in the `integration` layer's cross-source identity resolution must never be treated as equal** — a naive join silently merges every NULL-keyed row from `crm_contact` with every NULL-keyed row from `web_events_conversion` into one fabricated "entity" — pinned in Task 31.
- **`teardown.py` must succeed, or clearly report what's left, even after a partially-failed `tofu apply`** (a real risk when provisioning across two clouds/platforms in one run) — pinned in Task 38.

```python
"""The local Platform: a laptop, or CI with no real secret store or catalog.

`acquire_token` uses `azure-identity`'s `DefaultAzureCredential` by
default - the operator's own `az login` locally, or workload identity in
CI - so the dev-tier loop stays as secretless as the real platforms.
`azure-identity` is only imported when a token is actually requested and
no credential was injected, keeping it an optional dependency (the
`azure` extra) for everyone who doesn't need it.
"""

from __future__ import annotations

import os
from pathlib import Path
from typing import Any


class LocalPlatform:
    name = "local"

    def __init__(self, *, token_credential: Any = None) -> None:
        self._token_credential = token_credential

    def resolve_secret(self, name: str) -> str:
        env_var = _env_var_name(name)
        value = os.environ.get(env_var)
        if value is None:
            raise KeyError(
                f"secret {name!r}: environment variable {env_var} is not set "
                "(local platform resolves secrets from the environment)"
            )
        return value

    def qualify_table_name(self, fqn: str) -> str:
        return fqn

    def resolve_path(self, relative_path: str, base_dir: Path) -> str:
        return str(base_dir / relative_path)

    def run_metadata(self) -> dict[str, str]:
        return {}

    def acquire_token(self, resource: str) -> str:
        credential = self._token_credential
        if credential is None:
            from azure.identity import DefaultAzureCredential

            credential = DefaultAzureCredential()
        return credential.get_token(f"{resource}/.default").token


def _env_var_name(secret_name: str) -> str:
    return secret_name.upper().replace("-", "_").replace(" ", "_")
```

```python
class SqlServerSource:
    _AAD_TOKEN_RESOURCE = "https://database.windows.net/"

    def read(self, ctx: SourceContext) -> DataFrame:
        system = ctx.system
        fqn = ctx.table.fqn

        host = resolve_value(_required(getattr(system, "host", None), "host", fqn), ctx.platform)
        database = resolve_value(
            _required(getattr(system, "database", None), "database", fqn), ctx.platform
        )

        if ctx.table.source is None:
            raise ValueError(f"{fqn}: a sqlserver table needs a 'source' block")
        object_name = ctx.table.source.object

        url = (
            f"jdbc:sqlserver://{host};databaseName={database};"
            "encrypt=true;trustServerCertificate=false"
        )
        reader = ctx.spark.read.format("jdbc").option("url", url).option("dbtable", object_name)

        auth = _required(getattr(system, "auth", None), "auth", fqn)
        mode = auth.get("mode", "password")
        if mode == "aad_token":
            token = ctx.platform.acquire_token(self._AAD_TOKEN_RESOURCE)
            reader = reader.option("accessToken", token)
        elif mode == "password":
            user = resolve_value(_required(auth.get("user"), "auth.user", fqn), ctx.platform)
            password = resolve_value(
                _required(auth.get("password"), "auth.password", fqn), ctx.platform
            )
            reader = reader.option("user", user).option("password", password)
        else:
            raise ValueError(
                f"{fqn}: sqlserver auth.mode must be 'password' or 'aad_token', got {mode!r}"
            )

        for option_name in _PARTITION_OPTIONS:
            value = getattr(system, option_name, None)
            if value is not None:
                reader = reader.option(option_name, str(value))

        return reader.load()
```

```python
        system = ctx.system

        cluster = resolve_value(
            _required(getattr(system, "cluster", None), "cluster", fqn), ctx.platform

        )

            raise ValueError(f"{fqn}: a kusto table needs a 'source' block")
        table_name = ctx.table.source.object

        auth = _required(getattr(system, "auth", None), "auth", fqn)
        mode = auth.get("mode", "app_secret")

        reader = (
            ctx.spark.read.format(_FORMAT)
            .option("kustoCluster", cluster)
            .option("kustoDatabase", database)
            .option("kustoTable", table_name)
        )

        if mode == "aad_token":

                .option("kustoAadAppSecret", app_secret)
                .option("kustoAadAuthorityID", authority)
            )
```

- [ ] **Step 1: Bootstrap the remote state storage account (once, by hand)**

OpenTofu can't create the storage account it stores its own state in - this one-time bootstrap uses the operator's own `az login`, same secretless principle as everything else:

```bash
az group create -n rg-pipetree-scale-bench-state -l westeurope
az storage account create \
  -n ptsbtfstate -g rg-pipetree-scale-bench-state -l westeurope \
  --sku Standard_LRS --kind StorageV2 --allow-shared-key-access false
az storage container create \
  --account-name ptsbtfstate --name tfstate --auth-mode login
```

`--allow-shared-key-access false` disables account-key auth on the state storage account itself - OpenTofu authenticates to it via `az login`/OIDC too.

```python
"""Turns `scale_factor` (total data size in GB) into a row count per
table, per the spec's sizing model: three size classes splitting the
budget 70% huge / 25% medium / 5% small, with small tables using a
fixed row count instead of a budget share - dimension and reference
data doesn't grow 2000x just because the event stream did.
"""

from __future__ import annotations

from dataclasses import dataclass
from enum import Enum


class SizeClass(str, Enum):
    HUGE = "huge"
    MEDIUM = "medium"
    SMALL = "small"


_CLASS_BUDGET_FRACTION: dict[SizeClass, float] = {
    SizeClass.HUGE: 0.70,
    SizeClass.MEDIUM: 0.25,
    SizeClass.SMALL: 0.05,
}

# Rough bytes-per-row estimate per size class, used to turn a GB budget
# into a row count. Wide event/fact rows average ~200 bytes; medium
# transactional rows (more columns) ~500 bytes. Small tables are sized
# directly by SMALL_FIXED_ROW_COUNTS instead, never by budget.
_BYTES_PER_ROW: dict[SizeClass, int] = {
    SizeClass.HUGE: 200,
    SizeClass.MEDIUM: 500,
}

# table_name -> row count, independent of scale_factor. Populated by each
# system task (18-27) that owns small tables.
SMALL_FIXED_ROW_COUNTS: dict[str, int] = {}


@dataclass(frozen=True)
class TableSizeSpec:
    table_name: str
    size_class: SizeClass
    weight: float = 1.0  # relative share of its class's budget


def row_count_for(
    spec: TableSizeSpec,
    scale_factor_gb: float,
    tables_in_class: list[TableSizeSpec],
) -> int:
    if spec.size_class is SizeClass.SMALL:
        try:
            return SMALL_FIXED_ROW_COUNTS[spec.table_name]
        except KeyError:
            raise KeyError(
                f"{spec.table_name}: small tables need a fixed row count in "
                "SMALL_FIXED_ROW_COUNTS"
            ) from None

    class_budget_gb = scale_factor_gb * _CLASS_BUDGET_FRACTION[spec.size_class]
    total_weight = sum(t.weight for t in tables_in_class if t.size_class is spec.size_class)
    table_budget_gb = class_budget_gb * (spec.weight / total_weight)
    bytes_per_row = _BYTES_PER_ROW[spec.size_class]
    return max(1, int(table_budget_gb * 1_000_000_000 / bytes_per_row))
```

```python
"""Destination writers for generated data. Every write overwrites rather
than appends - regenerating a scale tier (fixing a bug, re-running the
same tier) must never duplicate rows. This is the property that makes
the whole generation step safely re-runnable.
"""

from __future__ import annotations

from typing import TYPE_CHECKING

if TYPE_CHECKING:
    from pyspark.sql import DataFrame


def write_to_adls(df: DataFrame, path: str) -> None:
    df.write.format("delta").mode("overwrite").save(path)


def write_to_sql(df: DataFrame, url: str, dbtable: str, access_token: str) -> None:
    (
        df.write.format("jdbc")
        .option("url", url)
        .option("dbtable", dbtable)
        .option("accessToken", access_token)
        .mode("overwrite")
        .save()
    )
```

```python
files, read back via the `d365_export` SourceReader). Referential
integrity comes from sampling a child table's foreign key uniformly
over [1, parent_row_count] - the parent's key column is always
generated as unique over exactly that range, so every FK resolves.
Simpler than dbldatagen's cross-table join generator, and just as
correct for this purpose.
"""

from __future__ import annotations

from typing import TYPE_CHECKING

import dbldatagen as dg

from generation.sizing import SMALL_FIXED_ROW_COUNTS, SizeClass, TableSizeSpec, row_count_for

if TYPE_CHECKING:
    from pyspark.sql import DataFrame, SparkSession

TABLES = [
    TableSizeSpec("customer", SizeClass.MEDIUM, weight=1.0),
    TableSizeSpec("vendor", SizeClass.SMALL),
    TableSizeSpec("product", SizeClass.SMALL),
    TableSizeSpec("address", SizeClass.SMALL),
    TableSizeSpec("gl_account", SizeClass.SMALL),
    TableSizeSpec("sales_order_header", SizeClass.HUGE, weight=1.5),
    TableSizeSpec("sales_order_line", SizeClass.HUGE, weight=2.5),
    TableSizeSpec("purchase_order", SizeClass.MEDIUM, weight=0.6),
    TableSizeSpec("gl_transaction", SizeClass.MEDIUM, weight=0.8),
    TableSizeSpec("inventory", SizeClass.SMALL),
]

SMALL_FIXED_ROW_COUNTS.update(
    vendor=500, product=5_000, address=20_000, gl_account=300, inventory=5_000
)

def _rows(table_name: str, scale_factor_gb: float) -> int:
    spec = next(t for t in TABLES if t.table_name == table_name)
    class_tables = [t for t in TABLES if t.size_class is spec.size_class]
    return row_count_for(spec, scale_factor_gb, class_tables)
```

```python
"""Shared Event Hub producer for the two doubled systems (web_events,
iot_telemetry). `to_eventhub_payload` is pure and tested directly;
`write_to_eventhub` is the real network write - see this task's
verification note in the plan for what's unconfirmed about it.
"""

from __future__ import annotations

from typing import TYPE_CHECKING

from pyspark.sql import functions as F

if TYPE_CHECKING:
    from pyspark.sql import DataFrame


def to_eventhub_payload(df: DataFrame) -> DataFrame:
    return df.select(F.to_json(F.struct("*")).alias("value"))


def write_to_eventhub(
    df: DataFrame, namespace_fqdn: str, eventhub_name: str, access_token: str
) -> None:
    (
        to_eventhub_payload(df)
        .write.format("kafka")
        .option("kafka.bootstrap.servers", f"{namespace_fqdn}:9093")
        .option("topic", eventhub_name)
        .option("kafka.security.protocol", "SASL_SSL")
        .option("kafka.sasl.mechanism", "OAUTHBEARER")
        .option(
            "kafka.sasl.jaas.config",
            "kafkashaded.org.apache.kafka.common.security.oauthbearer.OAuthBearerLoginModule "
            f'required unsecuredLoginStringClaim_sub="{access_token}";',
        )
        .save()
    )
```

```python
    "campaign", "campaign_channel", "ad_spend", "email_event",
    "lead_source", "conversion_attribution",
}


@app.route(route="{table_name}", methods=["GET"], auth_level=func.AuthLevel.ANONYMOUS)
def get_table(req: func.HttpRequest) -> func.HttpResponse:
    table_name = req.route_params.get("table_name")
    if table_name not in _TABLES:
        return func.HttpResponse(
            json.dumps({"error": f"unknown table {table_name!r}"}),
            status_code=404,
```

```python
"""Operator entrypoint: `uv run python scripts/generate.py --scale-tier dev`.
Generates every system's tables for one scale tier and writes them to
their real destinations - ADLS (files), Azure SQL DB (hr/finance/
support), Event Hub (web_events/iot_telemetry), and the marketing
Function's seed directory. Re-running for the same tier is safe
(generation.writers overwrites, never appends - see Task 17).
"""

from __future__ import annotations

import sys

from pipetree.platform.base import Platform
from pipetree.platform.databricks import DatabricksPlatform

from generation import (
    crm,
    erp,
    finance,
    hr,
    iot_telemetry,
    marketing,
    reference,
    supply_chain,
    support,
    web_events,
)
from generation.eventhub_producer import write_to_eventhub
from generation.writers import write_to_adls, write_to_sql

SCALE_FACTOR_GB = {"dev": 5, "tier1": 1000, "tier2": 10000}

_SQL_RESOURCE = "https://database.windows.net/"
_EVENTHUB_RESOURCE = "https://eventhubs.azure.net/"


def run(
    scale_tier: str, platform: Platform, sql_server_fqdn: str, eventhub_namespace_fqdn: str
) -> None:
    if scale_tier not in SCALE_FACTOR_GB:
        raise ValueError(
            f"scale_tier must be one of {sorted(SCALE_FACTOR_GB)}, got {scale_tier!r}"
        )
    scale_factor_gb = SCALE_FACTOR_GB[scale_tier]

    from pyspark.sql import SparkSession

    spark = SparkSession.getActiveSession()
    if spark is None:
        raise RuntimeError("run() expects to be called on a cluster with an active SparkSession")

    _generate_adls_system(erp, spark, scale_factor_gb, base_path="abfss://bronze@lake/erp")
    _generate_adls_system(crm, spark, scale_factor_gb, base_path="abfss://bronze@lake/crm")
    _generate_adls_system(
        supply_chain, spark, scale_factor_gb, base_path="abfss://bronze@lake/supply_chain"
    )

    sql_url = f"jdbc:sqlserver://{sql_server_fqdn};encrypt=true;trustServerCertificate=false"
    _generate_sql_system(hr, spark, scale_factor_gb, platform, sql_url, database_schema="hr")
    _generate_sql_system(
        finance, spark, scale_factor_gb, platform, sql_url, database_schema="finance"
    )
    _generate_sql_system(
        support, spark, scale_factor_gb, platform, sql_url, database_schema="support"
    )

    for table_name, df in reference.generate_all(spark).items():
        write_to_adls(df, f"abfss://bronze@lake/reference/{table_name}")

    marketing_tables = marketing.generate_all(spark)
    marketing.write_seed_json(marketing_tables, "generation/marketing_api/seed")

    eventhub_token = platform.acquire_token(_EVENTHUB_RESOURCE)
    for table_name, df in web_events.generate_all(spark, scale_factor_gb).items():
        write_to_eventhub(
            df,
            namespace_fqdn=eventhub_namespace_fqdn,
            eventhub_name="web-events",
            access_token=eventhub_token,
        )
    for table_name, df in iot_telemetry.generate_all(spark, scale_factor_gb).items():
        write_to_eventhub(
            df,
            namespace_fqdn=eventhub_namespace_fqdn,
            eventhub_name="iot-telemetry",
```

```python
"""Generates pipelines/pipeline.yaml's `systems` and `bronze` blocks from
the same TABLES registries generation/*.py already defines - one
generator, no drift between what generation actually produces and what
pipetree reads back, and no need to hand-write ~90 near-identical bronze
blocks. `main` merges into the existing file rather than overwriting it,
so silver/integration/gold/mart (hand-written, Tasks 30-34) survive a
re-run of this script.
"""

from __future__ import annotations

import os

import yaml

from generation import (
    crm,
    erp,
    finance,
    hr,
    iot_telemetry,
    marketing,
    reference,
    supply_chain,
    support,
    web_events,
)

# system name -> (module, source type, business-key column pattern; None = no key needed)
_SYSTEMS = {
    "erp": (erp, "d365_export", "{table}_id"),
    "crm": (crm, "synapse_link", "{table}_id"),
    "hr": (hr, "sqlserver", "{table}_id"),
    "finance": (finance, "sqlserver", "{table}_id"),
    "support": (support, "sqlserver", "{table}_id"),
    "supply_chain": (supply_chain, "storage_stream", "{table}_id"),
    "reference": (reference, "csv", None),
    "marketing": (marketing, "custom", "{table}_id"),
}

# The two doubled systems land two bronze blocks each - one per read path.
_DOUBLED_SYSTEMS = {
    "web_events": (web_events, "kusto", "storage_stream"),
    "iot_telemetry": (iot_telemetry, "kusto", "storage_stream"),
}


def build_systems_block() -> dict:
    systems: dict = {}
    for name, (_module, source_type, _key) in _SYSTEMS.items():
        systems[name] = {"type": source_type}
    for name, (_module, kusto_type, stream_type) in _DOUBLED_SYSTEMS.items():
        systems[f"{name}_kusto"] = {"type": kusto_type}
        systems[f"{name}_files"] = {"type": stream_type}
    return systems


def build_bronze_tables() -> dict:
    tables: dict = {}

    for system_name, (module, _source_type, key_pattern) in _SYSTEMS.items():
        for spec in module.TABLES:
            table_name = f"{system_name}_{spec.table_name}"
            entry: dict = {
                "source": {"system": system_name, "object": spec.table_name},
                "strategy": "replace" if key_pattern is None else "scd1",
            }
            if key_pattern is not None:
                entry["business_key"] = [key_pattern.format(table=spec.table_name)]
            tables[table_name] = entry

    for system_name, (module, _kusto_type, _stream_type) in _DOUBLED_SYSTEMS.items():
        for spec in module.TABLES:
            for suffix in ("kusto", "files"):
                table_name = f"{system_name}_{spec.table_name}_{suffix}"
                tables[table_name] = {
                    "source": {"system": f"{system_name}_{suffix}", "object": spec.table_name},
                    "strategy": "append",
                }

    return tables


def main(path: str = "pipelines/pipeline.yaml") -> None:
    existing: dict = {}
    if os.path.exists(path):
        with open(path) as f:
            existing = yaml.safe_load(f) or {}

    existing["defaults"] = existing.get("defaults", {"schema_policy": "evolve"})
    existing["systems"] = build_systems_block()
    existing["bronze"] = {"tables": build_bronze_tables()}

    with open(path, "w") as f:
        yaml.safe_dump(existing, f, sort_keys=False)


if __name__ == "__main__":
    main()
```

```python
# notebooks/integration/customer.py
# one output table per file: this is integration.customer
#
# Cross-source identity resolution by email. The join predicate is a
# plain `=`, deliberately not eqNullSafe/`<=>`: SQL's three-valued logic
# makes `NULL = NULL` evaluate to NULL (not true), so two rows with no
# email never match on either side. eqNullSafe would instead fuse every
# NULL-keyed crm_contact row with every NULL-keyed web_events_conversion
# row into one fabricated "entity" - exactly the bug this file must not
# have.
from pyspark.sql import functions as F

crm_contact = spark.table("silver.crm_contact")  # noqa: F821
web_conversion = spark.table("bronze.web_events_conversion_kusto")  # noqa: F821

crm_keyed = crm_contact.select(
    F.col("contact_id").alias("crm_contact_id"), F.col("email").alias("crm_email")
)
web_keyed = web_conversion.select(
    F.col("conversion_id").alias("web_conversion_id"), F.col("email").alias("web_email")
)

matched = crm_keyed.join(web_keyed, crm_keyed.crm_email == web_keyed.web_email, "outer")

result = matched.select(
    F.coalesce(F.col("crm_email"), F.col("web_email")).alias("email"),
    F.col("crm_contact_id"),
    F.col("web_conversion_id"),
)
```

```python
payment = spark.table("silver.finance_payment")  # noqa: F821

invoice_by_month = (
    invoice.withColumn("period", F.date_trunc("month", invoice.issued_at))
    .groupBy("period")
    .agg(F.sum("amount").alias("invoiced_amount"))
)

    payment.withColumn("period", F.date_trunc("month", payment.paid_at))
    .groupBy("period")
    .agg(F.sum("amount").alias("paid_amount"))

result = joined.select(
    F.coalesce(invoice_by_month.period, payment_by_month.period).alias("period"),
    F.coalesce(F.col("invoiced_amount"), F.lit(0)).alias("invoiced_amount"),
```

```python
"""Databricks entrypoint for pipetree-scale-bench's real pipeline.

Run as a `spark_python_task` via the Databricks Asset Bundle in this
directory (`databricks bundle deploy -t <scale_tier> && databricks bundle
run pipetree_scale_bench -t <scale_tier>`) - see README.md.

Parameters (positional, matching databricks.yml): catalog,
sql_service_credential, loganalytics_service_credential, config_path.
"""

from __future__ import annotations

import sys
from pathlib import Path

from pyspark.sql import SparkSession

from pipetree import run_pipeline
from pipetree.adapters.spark.adapter import SparkAdapter
from pipetree.config.loader import load_config
from pipetree.model import PipelineConfig
from pipetree.platform.databricks import DatabricksPlatform

CATALOG = sys.argv[1]
SQL_SERVICE_CREDENTIAL = sys.argv[2]
LOGANALYTICS_SERVICE_CREDENTIAL = sys.argv[3]
CONFIG_PATH = (
    Path(sys.argv[4])
    if len(sys.argv) > 4
    else Path(__file__).resolve().parent.parent.parent / "pipelines" / "pipeline.yaml"
)

_SQL_RESOURCE = "https://database.windows.net/"
_LOGANALYTICS_RESOURCE = "https://api.loganalytics.io/"


def main() -> int:
    dbutils = globals()["dbutils"]  # injected by the Databricks runtime, same reasoning as pipetree's own example

    spark = SparkSession.getActiveSession()
    if spark is None:
        raise RuntimeError(
            "no active SparkSession - this script expects to run on a Databricks cluster"
        )

    raw = load_config(CONFIG_PATH)
    config = PipelineConfig.from_validated_raw(raw)

    platform = DatabricksPlatform(
        dbutils=dbutils,
        catalog=CATALOG,
        secret_scope="pipetree",  # fallback only - real connections use service_credentials below
        service_credentials={
            _SQL_RESOURCE: SQL_SERVICE_CREDENTIAL,
            _LOGANALYTICS_RESOURCE: LOGANALYTICS_SERVICE_CREDENTIAL,
        },
    )
    adapter = SparkAdapter(
        spark, systems=config.systems, base_dir=CONFIG_PATH.parent, platform=platform
    )

    digest = run_pipeline(CONFIG_PATH, adapter=adapter)
    return digest.exit_code


if __name__ == "__main__":
    sys.exit(main())
```

```python
"""Builds the per-scale-tier load-test report from `_meta.pipeline_run_log`
(correctness + performance) plus a cost figure the caller supplies - see
the spec's Validation & reporting section for where that number comes
from (Cost Management API, or SKU x duration)."""

from __future__ import annotations

from dataclasses import dataclass
from typing import TYPE_CHECKING

from pyspark.sql import functions as F

if TYPE_CHECKING:
    from pyspark.sql import SparkSession

_UNEXPECTED_STATUSES = ("failed", "upstream_failed")


@dataclass(frozen=True)
class CorrectnessSummary:
    total_tables: int
    succeeded: int
    unexpected_failures: list[str]

    @property
    def clean(self) -> bool:
        return not self.unexpected_failures


@dataclass(frozen=True)
class PerformanceSummary:
    total_duration_ms: int
    by_layer_ms: dict[str, int]


def correctness_summary(spark: SparkSession, execution_id: int) -> CorrectnessSummary:
    rows = (
        spark.table("_meta.pipeline_run_log")
        .filter(F.col("_execution_id") == execution_id)
        .select("table_fqn", "status")
        .collect()
    )
    unexpected = [r.table_fqn for r in rows if r.status in _UNEXPECTED_STATUSES]
    succeeded = sum(
        1 for r in rows if r.status not in _UNEXPECTED_STATUSES and r.status != "skipped"
    )
    return CorrectnessSummary(
        total_tables=len(rows), succeeded=succeeded, unexpected_failures=unexpected
    )


def performance_summary(spark: SparkSession, execution_id: int) -> PerformanceSummary:
    df = spark.table("_meta.pipeline_run_log").filter(F.col("_execution_id") == execution_id)
    total = df.agg(F.sum("duration_ms")).first()[0] or 0
    by_layer = {
        row.layer: int(row.total_ms)
        for row in df.groupBy("layer").agg(F.sum("duration_ms").alias("total_ms")).collect()
    }
    return PerformanceSummary(total_duration_ms=int(total), by_layer_ms=by_layer)


def write_report(
    scale_tier: str,
    execution_id: int,
    correctness: CorrectnessSummary,
    performance: PerformanceSummary,
    cost_usd: float,
    output_path: str,
) -> None:
    failures_note = (
        f" ({', '.join(correctness.unexpected_failures)})" if correctness.unexpected_failures else ""
    )
    lines = [
        f"# Load test report - {scale_tier} (_execution_id={execution_id})",
        "",
        "## Correctness",
        f"- Tables run: {correctness.total_tables}",
        f"- Succeeded: {correctness.succeeded}",
        f"- Unexpected failures: {len(correctness.unexpected_failures)}{failures_note}",
        "",
        "## Performance",
        f"- Total duration: {performance.total_duration_ms / 1000:.1f}s",
        "- By layer:",
        *[f"  - {layer}: {ms / 1000:.1f}s" for layer, ms in sorted(performance.by_layer_ms.items())],
        "",
        "## Cost",
        f"- ${cost_usd:.2f}",
    ]

    with open(output_path, "w") as f:
        f.write("\n".join(lines) + "\n")
```

```python
"""scripts/teardown.py - `uv run python scripts/teardown.py --scale-tier dev`.

Tears down a scale tier's Azure estate. Never assumes the `tofu apply`
that created it fully succeeded - `tofu destroy` removes whatever IS in
state regardless, so a partial apply is not a blocker. Retries once on
failure (many Azure teardown errors are transient - a role assignment
mid-propagation, a dependent resource not yet released), then reports
exactly what's left in state rather than silently declaring success.
"""

from __future__ import annotations

import argparse
import subprocess
from dataclasses import dataclass


@dataclass(frozen=True)
class TeardownResult:
    succeeded: bool
    remaining_resources: list[str]
    raw_output: str


def teardown(scale_tier: str, infra_dir: str = "infra") -> TeardownResult:
    var_file = f"environments/{scale_tier}.tfvars"

    result = _run_destroy(infra_dir, var_file)
    if result.returncode != 0:
        result = _run_destroy(infra_dir, var_file)

    remaining = _list_remaining_resources(infra_dir) if result.returncode != 0 else []

    return TeardownResult(
        succeeded=result.returncode == 0,
        remaining_resources=remaining,
        raw_output=result.stdout + result.stderr,
    )


def _run_destroy(infra_dir: str, var_file: str) -> subprocess.CompletedProcess:
    return subprocess.run(
        ["tofu", "destroy", "-var-file", var_file, "-auto-approve"],
        cwd=infra_dir,
        capture_output=True,
        text=True,
    )


def _list_remaining_resources(infra_dir: str) -> list[str]:
    result = subprocess.run(
        ["tofu", "state", "list"], cwd=infra_dir, capture_output=True, text=True
    )
    if result.returncode != 0:
        return []
    return [line for line in result.stdout.splitlines() if line.strip()]


_MANUAL_FALLBACK_REMINDER = """
Reminder: resources created via a manual fallback are NOT tracked in
OpenTofu state and are NOT removed by this script - clean these up by
hand if you used them:
  - the mssql_user/mssql_user_permission T-SQL fallback (infra Task 10)
  - the fabric_shortcut REST API fallback (infra Task 15)
"""


def main() -> None:
    parser = argparse.ArgumentParser()
    parser.add_argument("--scale-tier", required=True, choices=["dev", "tier1", "tier2"])
    args = parser.parse_args()

    result = teardown(args.scale_tier)

    if result.succeeded:
        print(f"{args.scale_tier}: torn down cleanly.")
    else:
        print(f"{args.scale_tier}: teardown FAILED. Resources still in state:")
        for resource in result.remaining_resources:
            print(f"  - {resource}")
        print("Re-run this script, or `tofu destroy` by hand in infra/, to finish.")

    print(_MANUAL_FALLBACK_REMINDER)


if __name__ == "__main__":
    main()
```

```python
"""scripts/run.py - `uv run python scripts/run.py --scale-tier dev
--execution-id <id> --cost-usd <figure>`.

Trigger the run itself via runners/databricks (`databricks bundle run
...`) or runners/fabric (open the notebook), note the `_execution_id`
pipetree's digest prints, then call this to produce

from __future__ import annotations

import argparse
import datetime as dt

from pyspark.sql import SparkSession

from scripts.report import correctness_summary, performance_summary, write_report


def run(scale_tier: str, execution_id: int, cost_usd: float) -> str:
    spark = SparkSession.getActiveSession()
    if spark is None:

            "run() expects an active SparkSession - the same cluster/session pipetree just ran on"
        )

    performance = performance_summary(spark, execution_id)

    output_path = f"reports/{scale_tier}-{dt.date.today().isoformat()}.md"
    write_report(scale_tier, execution_id, correctness, performance, cost_usd, output_path)
    return output_path

    path = run(args.scale_tier, args.execution_id, args.cost_usd)
    print(f"Report written to {path}")


if __name__ == "__main__":
    main()
```
