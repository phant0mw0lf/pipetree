# Security policy

## Supported versions

Only the latest release receives security fixes.

## Reporting a vulnerability

Please do not open a public issue for a security problem. Report it privately
through GitHub's private vulnerability reporting: open the repository's
**Security** tab and choose **Report a vulnerability**
(<https://github.com/phant0mw0lf/pipetree/security/advisories/new>).

Include what you found, the affected version, and steps to reproduce. You will
get a reply as soon as possible; a fix is released and credited in the
advisory once it is ready.
